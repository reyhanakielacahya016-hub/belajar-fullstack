# Belajar Fullstack

Catatan perjalananku dari nol sampai fullstack developer, dengan aplikasi
[Tirta Agung](https://github.com/reyhanakielacahya016-hub/tirta-agung) sebagai studi kasus.

## Rencana belajarku

- **Target**: siap magang sebagai developer, bisa membuat proyek sendiri, dan memahami Tirta Agung.
- **Waktu**: sekitar 4 jam per minggu, 4 sesi × 45–60 menit.
- **Jalur**: HTML & CSS → JavaScript → TypeScript + React → Database & Supabase → Mobile (Expo)
  → Mid-level → Pola pikir senior.
- **Milestone**: Junior sekitar bulan ke-8, Mid sekitar bulan ke-13–14.

Progres terbaru ada di [PROGRES.md](PROGRES.md).

## Isi repo

- `PROGRES.md`: checklist, posisi belajar sekarang, dan log sesi.
- `CLAUDE.md`: konteks untuk tutor Claude, dimuat otomatis setiap sesi.
- Folder mini proyek tiap fase akan ditambahkan di sini.
